# 點亮第一顆 LED — 單元一接線遊戲

## 已實作

入口：`/games/uno-wiring`；GitHub Pages 正式路徑加 `/LUISIR-ict-game-lab`。已在遊戲目錄登記為第二個遊戲，並保留既有 Mars 遊戲。

對象是中三學生，Windows 電腦、滑鼠操作，實物課前練習。目標是獨立接線、連接電腦、選板及連接埠、補程式及上傳，先令 LED 亮起，再上傳 LOW 令它熄滅。課堂預算 8–10 分鐘，沒有倒數或速度評分。

1. 第一輪採用六步接線：LED 長腳 a8 → 短腳 a10 → 電阻第 1 端 e4 → 第 2 端 e8 → Uno D8 接 a4 → Uno GND 接 e10。起始已選 LED 長腳，接對自動帶到下一個元件端點；錯接保留選取以便直接改孔。電阻在 LED 接妥後出現，Uno 腳位在元件接妥後解鎖。LED 與電阻均有形狀示意，D8／D7／5V／GND 是開發板上可直接點擊的按鈕，沒有腳位下拉選单。接受指定孔的同組空孔。
2. 第二輪重設接線、USB、板型、連接埠、編輯程式、板上程式及提示次數。只提供 D8 → 電阻 → LED → GND 目標，接受任意符合此路徑的孔位，含右側孔及電阻端點對調。沒有強制換位限制。
3. 第二輪零提示完成 HIGH 亮起、LOW 熄滅，顯示「獨立完成」。用過提示則顯示「提示協助下完成」，可立即重試。錯誤及安全回饋不計提示。
4. 接線與電腦分成兩個畫面。第一輪接妥正確電路才可進入電腦畫面，第二輪可自由切換。電腦畫面保留 LED 即時狀態與返回接線按鈕。USB 線以 Windows 電腦、接頭及 Uno 示意呈現。IDE 1.8.18 教學介面提供工具選單、Uno/Mega、COM1/COM3、驗證與上傳。USB 用一個按鈕模擬兩端接好，COM3 隨連接出現；真實電腦編號不固定。這不是完整 IDE 或真實 USB 連線。
5. 程式固定骨架，補 OUTPUT/INPUT、8/7、HIGH/LOW。INPUT 或 D7 是可編譯但不能完成本課目標的選項。驗證只檢查空缺，上傳亦會先檢查，因此不強制先按驗證；上傳功能本身具有編譯步驟。電腦編輯與板上程式分離，修改或驗證不會改變板上輸出。斷電熄燈，重新連接會執行已上傳程式。
6. 一孔限一端點；a–e 同列相通、f–j 同列相通，中央凹槽不相通。線跨過孔不建立連接。接電後禁止改線；直接短接供電/輸出與 GND、LED 未串聯限流電阻，在通電前攔截。反接 LED、開路、錯腳位及同組 LED 腳不亮。
7. 接線及 Uno 腳位選擇後即時檢查，錯誤原因與改法同時顯示在上方固定訊息列及接線區，保留當前元件選取以便立即改正。第一輪檢查指定相通孔組（接受同組空孔）；第二輪只檢查已建立的電路關係，不把尚未完成但仍可正確接通的電路判為錯誤。修正後立即清除警示。即時回饋不計提示次數；「給我線索」仍提供額外逐層協助。

## 範圍與限制

這是固定材料的教學電路模型，非通用 SPICE 模擬器；未模擬電流數值、USB 驅動安裝、USB 插頭方向、接觸不良、元件損壞或完整文字輸入。電阻固定 220 Ω，不含閃爍課題。相通孔標示可隨時閱讀，不算提示。頁面重新整理會清除進度；沒有帳戶、學生資料、聲音或伺服器儲存。

端點有文字及符號，並非只靠顏色。使用原生按鈕與下拉選單，支援鍵盤焦點；窄畫面上下排列，完整 Uno／麵包板接線圖容許內部橫捲，避免把孔位縮得太小。接線以短暫畫線動畫呈現，端點有落位動畫，LED 亮滅有漸變；不以閃爍暗示本課的 HIGH 輸出。減少動態效果偏好下關閉動畫、漸變及平滑捲動。訊息列捲動時固定在畫面上緣，並透過 live region 朗讀更新。
