# 三色燈實驗室 — 單元二

## 目標與入口

入口 `/games/three-light-lab`，正式 GitHub Pages 前綴 `/LUISIR-ict-game-lab`。遊戲庫編號 03，對應工作紙單元二，與遊戲庫編號 02 的單元一接線遊戲並存。

學生從空白工作枱接三色燈，理解共同接地、指令次序、燈號狀態保留及等待時間。主要使用 Windows 電腦滑鼠；適合教師示範後學生重玩。不設倒數；目標活動預算 8–10 分鐘，首次完整接線可按課堂需要延長。

## 已實作流程

1. **共同教學先於模式選擇。** 共同接地短動畫可播放、逐步前進及重播；單顆紅燈示範 HIGH → 等待 2 秒 → LOW → 等待 1 秒。可跳過教學，不扣分。教學不播放三色燈預測答案；任務中可重看教學。
2. **分層模式。** 練習模式預設打開逐步指定孔位，可隱藏；每次只突出目前要接的一孔。挑戰模式沒有指定孔位或額外解題提示，按「我需要提示」立即轉練習，保留接線、答案和進度，沒有再轉回挑戰的捷徑。初始選練習的學生即使未按提示也記為練習完成。
3. **逐顆接線。** 從紅 D8 開始，各自接 LED、220 Ω 電阻、訊號線及兩端回路線；Uno GND 接共用接地幹線。每顆先上傳 HIGH 再 LOW 通過，拔 USB 才加入綠 D9、黃 D10。三顆完成後才能前往預測。已加入燈可切換編輯；改線會清除該燈及受影響電路的測試紀錄，改共用幹線須重測全部燈。
4. **預測與對照。** 題目是紅 2 秒 → 黃 1 秒 → 綠 4 秒。先填三階段燈號與秒數，再逐行或自動播放；第一次預測保留顯示，學生可修改目前答案。觀察完成並核對正確才解鎖下一關。
5. **改時間。** 回到工作紙紅 3 秒 → 綠 3 秒 → 黃 1 秒程式，改成 5 / 3 / 1 秒，填完整循環 9 秒。指令可選腳位、HIGH/LOW、delay 毫秒；須上傳及觀察，驗證所有階段只亮正確一顆燈、時間與總秒數均正確。
6. **排錯。** 紅 3 秒 → 綠 3 秒 → 黃 1 秒程式，第二阶段漏了關掉紅燈的指令。空白行不改狀態，因此綠 HIGH 時紅仍亮。學生補回指令並選腳位、電平；執行結果符合目標才完成。
7. **結果。** 全程挑戰完成顯示「獨立完成」；練習或中途求提示則顯示「練習完成」。不要求最後再重新接三顆燈。

## 電路與模型界線

麵包板橫放顯示 1–26 與 a–j。相同數字的 a–e 相通、f–j 相通，中央凹槽分隔兩組；不用兩旁電源長軌。所有孔都是可點擊按鈕，Uno D8/D9/D10/GND 直接在板上選取。SVG、元件和線均為自行繪製，沒有外部素材。

指定孔位沿用工作紙：

| 燈 | LED 長/短腳 | 電阻 | 訊號 | 回路 LED 端 / 共用端 |
| --- | --- | --- | --- | --- |
| 紅 D8 | a8 / a10 | e4 / e8 | a4 | e10 / j2 |
| 綠 D9 | a16 / a18 | e12 / e16 | a12 | e18 / i2 |
| 黃 D10 | a24 / a26 | e20 / e24 | a20 | e26 / h2 |

Uno GND → f2。這些只是可選提示；規則使用相通孔及回路線的連通關係，接受其他正確孔位、不同共用接地組及電阻端點對調。禁止同孔重疊插線。偵測輸出直接接 GND、LED 正向支路繞過電阻及數位腳位互短；不是通用電路/電流/元件損壞模擬器。

為聚焦單元二，Uno 板型/連接埠環境已準備好；不是完整 IDE 1.8.18 介面。每顆測試要修改 pinMode 和 digitalWrite 兩個腳位，再上傳 HIGH/LOW。USB 是模擬按鈕；斷電後須重新上傳測試，沒有模擬永久快閃記憶體。程式任務的初始化設為三燈 LOW；展示 loop 內的指令，每次觀察一個循環。

播放時寫入指令刻意放慢到約 650 毫秒，delay 使用指定毫秒等待。循環秒數只計 delay，不包含教學播放用的慢速指令時間。可暫停、逐行前進及重播；沒有模擬串口或實際 USB 裝置。每次「上傳」保留程式快照，編輯後須重新上傳，不能以舊快照為新版本過關。

## 接線操作改善

LED、單顆電阻及回路線各有一個元件區，第一端放好後自動選第二端。操作提示及既有端點摘要在兩種模式均顯示；挑戰只隱藏答案孔位。點已接孔可選端點重新接線，Uno 選取狀態持續突出，兩端未完成時顯示虛線。共同教學使用完整 Uno 與麵包板，逐步呈現 e10→j2、e18→i2、e26→h2、f2→GND，並標示 f2–j2 內部相通。

麵包板 LED 與測試燈號同步；其他未完成支路不會阻止已接通 LED 回應程式，危險短路仍攔截通電。上傳成功與電路是否能亮分開回饋。時間及排錯上傳後自動播放並聚焦播放器。畫面突出「教學慢播」及程式等待總秒數；手動到最後一行即完成觀察，不必再按額外完成鍵。
