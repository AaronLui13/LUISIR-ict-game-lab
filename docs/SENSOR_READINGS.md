# 讓電腦看見光 — 單元三

## 來源與目標

依據用戶提供的 `Arduino 教學材料（新版）/03_感應器與電腦讀數_學生工作紙.pdf`（四頁）及 `課堂簡報/03_感應器與電腦讀數_中文版課堂簡報_v2.pdf`（十二頁）。保留原文件，沒有修改工作紙。入口 `/games/sensor-readings`，遊戲庫編號 04，教學單元編號 03；GitHub Pages 前綴 `/LUISIR-ict-game-lab`。

目標是接好感光分壓電路、讓電腦顯示原始輸入，再以自己的光暗數據支持結論。適合教師示範後獨立重玩，預計 8–10 分鐘，不設倒數。介面用繁體中文配重要英文詞彙。

## 已實作流程

1. 三段可跳過／重看的共同教學：輸入對比輸出、互動遮光示範、完整麵包板中間接點、讀取／儲存／傳送／等待指令。
2. 練習預設逐步突出目標孔；挑戰保留操作指示而隱藏孔位答案。使用提示轉練習並保留進度，不可再轉回挑戰。
3. 空白麵包板逐步接線。LDR 和電阻各顯示為一件兩腳元件，接第一腳自動選第二腳；線頭摘要、Uno 選取狀態及未完成虛線持續顯示。每孔只能插一端，點已接端點可改接。USB 連接時鎖定接線和電阻選擇。
4. 選 COM3、驗證、上傳，開啟 Serial Monitor，將監控速率與程式 9600 配合。預設監控視窗為 115200，讓學生實際觀察及修復速率不符的亂碼。可修改 A0/A1、println、速率與取樣間隔；本課程式檢核要求工作紙的 A0、println、9600、500 ms。這是教學檢核，不是 Arduino 編譯器。
5. 三種光度各等三個新讀數才可記錄。數值每半秒更新，保留十二筆最近取樣，呈現少量波動；切換條件清空即時樣本，防止把上一情況的讀數記入新情況。表格保留三次記錄，可重測覆蓋。
6. 從自己的表選光與暗的證據，辨認較高／較低趨勢、原始數值而非 lux，並選合理波動因素。答錯有回饋，可立即修改。
7. 自動斷電並只移除 A0，保留其他接線及先前數據表。隱藏指定孔位，學生接回後重新驗證、上傳及記錄光暗各三個讀數；可求提示。不要求拆掉整個電路。
8. 顯示練習／獨立完成，可下載本機純文字實驗記錄，內含三種光度數據、結論及重接後光暗數據。

## 接線與模型

| 部件 | 工作紙示範孔 |
| --- | --- |
| LDR | a4、a8 |
| 10 kΩ 固定電阻 | e8、e14 |
| Uno 5V | e4 |
| Uno GND | a14 |
| Uno A0 | c8 |

麵包板沿工作紙直放：字母 a–j 向右，數字 1–16 向下。同一數字 a–e 相通，f–j 相通，中間凹槽隔開。提示綠框標示第 8 列內部相通，不是額外元件。規則以相通孔判斷，接受其他正確配置及無極性元件端點對調，並非只比對示範孔。

5V 和 GND 直接相通會攔截通電。A0 接 5V／GND 分別顯示 1023／0；斷路不產生有效取樣，明確說明實物可能飄移。LDR 與固定電阻位置交換會產生相反趨勢，但不符合本課接法及過關條件。220 Ω 可以選，但本課要求 10 kΩ；既有 LED 用電阻不等於感光分壓電阻。

模型採簡化 LDR 電阻曲線與電壓分壓比例，轉為 0–1023 整數，加入可重現的小幅波動。未對真實 LDR 型號或 lux 校準，亦不是完整電路、電流或元件損壞模擬。預設參考電壓按工作紙採約 5 V。USB、COM3 及上傳均為模擬，沒有使用 Web Serial 或連接實物。

上傳保存程式快照；修改編輯器不會更改上次上傳程式。USB 斷電或改線後清除執行版本及當前階段的記錄，需重新上傳；獨立重接階段保留上一階段的證據表。Serial Monitor 不使用 live region 每半秒讀出，避免螢幕閱讀器被連續打斷；操作回饋使用 status。

## 使用與驗證

所有圖形自行以 SVG 繪製，無外部素材或新套件。鍵盤焦點清晰，按鈕支援鍵盤；麵包板及數據表在窄畫面內部橫捲。無聲音、帳戶、分析、伺服器儲存；重新整理清除進度。下載由瀏覽器產生，資料不傳送。

規則測試覆蓋同組替代孔、元件端點對調、短路、斷路、電阻選錯、A0 接電源軌、反向分壓、ADC 範圍、程式及通訊錯誤和證據核對。另驗證靜態匯出及網站入口。UI 需檢查完整流程、錯誤修正、挑戰轉練習、獨立重接及窄畫面。

### 遮光板互動

教學及實驗均提供可上下拖動的遮光板：拉低遮住 LDR，拉高讓光照入；光線及遮擋同步改變。支援滑鼠、觸控、↑↓、Home/End，保留三種光度按鈕。放手吸附到光線充足／稍微遮蓋／完全遮蓋的位置。拖動中暫停取樣及記錄，位置改變清除舊的即時樣本，放手後重新累積三次讀數。減少動態效果設定下取消平滑移動。

### 共同教學 2/3：電流示範

先請學生播放一次約十二秒的五步示範，亦可暫停或逐步觀看。金色箭嘴沿實際示範接線及麵包板內部相通孔，依序標示 5V → e4/a4 → LDR → a8/e8 → 10 kΩ → e14/a14 → GND，最後以靜態藍色標示 c8–A0 的電壓量度連接，不在 A0 線顯示電流流動。說明採傳統電流方向、分段為教學演示，並非電流真實傳播時間。完成一次播放或逐步觀察後開放本頁「下一段教學」，保留原有跳過整段教學入口。重看教學不改變學生電路；減少動態效果時保留箭嘴和文字、停用流動動畫。
